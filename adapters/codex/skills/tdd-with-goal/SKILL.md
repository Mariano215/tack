# TDD With Goal

1. Identify behavior and public interface.
2. Write smallest failing test.
3. Run it and confirm expected failure.
4. Implement minimal code.
5. Run test and confirm pass.
6. Refactor only when clarity improves without behavior change.
7. Run relevant regressions.

If no test harness exists, document that and add smallest practical verification.
