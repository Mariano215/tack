# Build With Goal

1. Define success criteria in one sentence.
2. Explore existing files, commands, patterns, and tests.
3. Decompose independent subsystems.
4. Propose approach when tradeoffs matter.
5. Write or update spec/plan for non-trivial work.
6. Implement smallest coherent slice.
7. Run targeted tests.
8. Report exact verification.

Keep diffs scoped. At iteration 4 without convergence, pause and offer strategy
reset or stop. Never claim success without passing evidence or a clear blocker.
